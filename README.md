# memories
This project includes a local development setup and environment variables for the backend.

Use your own values for the following variables in a local environment file:
- MONGO_URI
- PORT
- JWT_SECRET
- R2_BUCKET_NAME
- R2_BUCKET_API_TOKEN
- R2_ACCOUNT_ID
- R2_ACCESS_KEY_ID
- R2_SECRET_ACCESS_KEY
- R2_ENDPOINT
- CORS_ORIGINS
